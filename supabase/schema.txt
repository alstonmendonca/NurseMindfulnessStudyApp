Table: participants

participant_number (int4, PK) → Primary key, unique identifier for each participant

participant_password (text) → Hashed password for participant authentication

demographic_survey_completed (bool) → Whether participant has completed demographic survey

department (text) → Department or unit information (deprecated, kept for backward compatibility)

study_group (text) → Research study group assignment (e.g., control vs intervention)

created_at (timestamptz) → Timestamp when participant record was created

last_active (timestamptz) → Last time participant was active in the app

completed_onboarding (bool) → Whether participant completed onboarding (deprecated)

id_used (bool) → Flag to track if this participant ID has been used/activated

Group (varchar) → Study group assignment (alternative field name)

Table: app_usage_sessions

id (int4, PK) → Primary key

participant_number (int4) → Foreign key to participants.participant_number

session_start (timestamptz) → When the app was opened/session started

session_end (timestamptz) → When the app was closed/session ended

duration_minutes (int4) → Duration of the session in minutes

app_version (varchar) → App version for tracking

created_at (timestamptz) → Record creation timestamp
